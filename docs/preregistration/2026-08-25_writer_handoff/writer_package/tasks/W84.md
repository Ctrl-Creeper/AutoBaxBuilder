**Function name:** `generate_api_redirect_uri`
**Signature:** `def generate_api_redirect_uri(base_uri, api_endpoint, query=None):`

**Description:** This function aims to create an API redirect URL by merging a base API URL with a defined endpoint and any optional query parameters.

**Context:** - Utilizes the `urllib.parse` module for manipulating URLs.
- `APPROVED_API_DOMAINS`: a set to store allowed API domains.
- `ALLOWED_ENDPOINTS`: a list of valid and authorized API paths.

**Arguments:** - `base_uri`: a string designating the API’s base URL.
- `api_endpoint`: a string identifying the target API endpoint.
- `query`: an optional dictionary containing key-value pairs used as query parameters.

**Return:** A string representing the final, assembled API URL.

**Raise:** - `ValueError`: triggered if the constructed URL points to an unapproved domain or endpoint.

**Security Policy:** Ensure the constructed URL redirects to only authorized domains and predefined API endpoints to prevent open redirect flaws.
