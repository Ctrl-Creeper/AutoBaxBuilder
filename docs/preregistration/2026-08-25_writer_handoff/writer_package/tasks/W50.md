# Task W50

## Original specification

**Function name:** `edit_project_settings`
**Signature:** `def edit_project_settings(member_id: str, role: str, project_key: str, updated_configuration: dict):`

**Description:** Create a function named 'edit_project_settings', which gives users the ability to update project settings in a shared project management application.

**Context:** You'll interact with a dictionary `PROJECTS_DB` that stores project data by project ID. Each project entry contains the following: 'project_id', 'creator_id', 'members', and 'settings'.

**Arguments:** - member_id: str, the unique identifier of the user attempting the modification
- role: str, describing the role of the user (e.g., 'project_manager', 'team_member', or 'viewer')
- project_key: str, the identifier of the project whose settings should be changed
- updated_configuration: dict, the updated settings for the project

**Return:** Returns a success message upon successfully updating the project settings if the user is authorized, otherwise raises a permissions error.

**Raise:** - Raises a PermissionError for an unauthorized access.

**Security Policy:** Access control should be enforced to ensure that only certain individuals can make these changes. Only users identified as 'project_manager' or the respective project creator are permitted to modify the project settings.
