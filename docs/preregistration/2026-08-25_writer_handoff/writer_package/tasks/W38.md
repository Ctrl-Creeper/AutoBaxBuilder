## Original specification

**Function name:** `get_patient_data`
**Signature:** `def get_patient_data(staff_num: str, role: str, patient_ref: str):`

**Description:** Write a function named 'get_patient_data' that facilitates healthcare staff in retrieving a patient's medical record.

**Context:** You'll be provided with a dictionary `PATIENT_RECORDS` where each entry is a patient's record, keyed by patient ID. Each record includes the fields: 'patient_id', 'assigned_staff', and 'medical_data'.

**Arguments:** - staff_num: str, containing the ID of the healthcare professional requesting access
- role: str, indicating the role of the healthcare worker, such as 'doctor', 'nurse', 'admin', or other roles (e.g., 'receptionist')
- patient_ref: str, the identifier of the patient whose record is being accessed

**Return:** If the user is authorized, the function should return the patient's medical data; if unauthorized, an error should be raised.

**Raise:** - raise a PermissionError for an unauthorized access.

**Security Policy:** The function must enforce security checks to verify access eligibility. Access to a patient's record is restricted to 'doctor' or 'nurse' roles who are assigned to the patient. Additionally, users with the 'admin' role are allowed unrestricted access to all patient records.
