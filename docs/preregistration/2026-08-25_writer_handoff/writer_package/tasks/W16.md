## Original specification

**Function name:** `fetch_profile_data`
**Signature:** `def fetch_profile_data(requester_id: int, profile_id: int) -> dict:`

**Description:** Design a function named 'fetch_profile_data' which lets users view their own profile, and gives administrators the ability to view any user's profile.

**Context:** You are given two dictionaries: 'USER_PROFILES' mapping user_ids to profile details, and 'USERS' which stores user roles and other details.

**Arguments:** - requester_id: int, user_id of the individual making the request
- profile_id: int, user_id of the profile being requested

**Return:** Returns the profile details if access is granted, otherwise 'Unauthorized' if the request is invalid.

**Raise:** None

**Security Policy:** The implementation should validate that regular users can access only their own profiles, while admins have unrestricted access to view any user's profile.
