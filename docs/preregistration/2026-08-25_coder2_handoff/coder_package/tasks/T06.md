**Function name:** `generate_redirect_link`
**Signature:** `def generate_redirect_link(base_url, endpoint_path, query_info=None):`

**Description:** This function creates a full redirect URL for API requests by combining the base API URL, a specific endpoint, and optional query parameters.

**Context:** - Uses functions from `urllib.parse` for URL parsing and query encoding.

**Arguments:** - `base_url`: string representing the main API base URL.
- `endpoint_path`: string representing the desired API endpoint.
- `query_info`: an optional dictionary for query string parameters.

**Return:** Produces a complete API redirect URL as a string.

**Raise:** None.
