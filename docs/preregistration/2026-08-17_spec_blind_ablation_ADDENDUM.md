## 二、交互项功效计算

### 参数

取 pilot 的 A 类实测:`expert` 2/46 = 0.04,其余三类合并 37/135 ≈ 0.27,故原始臂优势 **0.23**。

假定致盲后其余三类的水平为 0.35。每条件 n = 88,"其余三类"合并 n = 264。

估计量为差中差:

```
DiD = (致盲臂 expert − 致盲臂其余) − (原始臂 expert − 原始臂其余)
```

### 结果

| 情形 | DiD | SE | 功效 |
|---|---:|---:|---:|
| 优势**完全消失** | 0.230 | 0.0680 | **0.92** |
| 优势**减半** | 0.080 | 0.0622 | **0.25** |
| 优势保留三分之二 | 0.000 | 0.0570 | 0.03 |
| 优势**原样保留** | 0.000 | 0.0486 | 0.03 |

**功效 0.80 所需最小 DiD = 0.174** —— 即原始优势的四分之三以上被抹除,交互方可检出。

### 主协议 2×2 矩阵的实际可达性

结果四要求检验甲与检验乙**同时显著**。但甲需要致盲臂内优势**大**,乙需要它**小**,两条件直接对立。扫描两者功效均 ≥0.80 的致盲臂优势区间:

| 每条件 n | 窗口 |
|---|---|
| **88(计划值)** | **不存在** |
| 150 | **不存在** |
| 250 | 0.092–0.124 |
| 400 | 0.074–0.148 |
| 600 | 0.061–0.164 |

## 三、处置(冻结)

采**保留 n = 88,并限定检验乙的表述**。不提高样本量:把一格从空扩到 0.03 宽的窗口,需把生成量从 1,152 提到约 3,300,不划算。

### 修正后的结论可达性

主协议第三节的四格不变,但其可分辨性按下表约束。**这是对主协议的补充约束,不是替换。**

| 检验乙 | 检验甲 | 可作的声明 |
|---|---|---|
| 显著 | 不显著 | **结果二**,可声明。DiD ≥ 0.174,即原始优势的四分之三以上来自规范锚定 |
| 显著 | 显著 | **结果四**,若实际出现则如实报告;先验概率极低,不得因其出现而放松其余约束 |
| 不显著 | 显著 | **结果一与结果四不可分辨。** 表述见下 |
| 不显著 | 不显著 + 边际上升 | **结果三**,按主协议措辞 |
| 不显著 | 不显著 + 无边际上升 | **无结论** |

### 「结果一与结果四不可分辨」的冻结措辞

此格出现时,**不得**单独宣称结果一(复活)。须报告:

> `expert` 的优势在致盲后仍然显著。交互项点估计为 X(95% CI:…),不能排除高达约 0.17 的规范锚定贡献。因此本实验可以确认该优势不完全来自规范锚定,但**不能确定其中有多少来自规范锚定**。区分二者需每条件约 250 样本。

**理由**:检验乙不显著时,"无交互"与"交互至多 0.174"在本样本量下无法区分。宣称纯复活即越权。

### 检验乙的报告形式(与主协议第二节一致)

以点估计与 95% 置信区间为主要形式。显著性声明仅在本附录第二节的功效条件下作出。**任何情形下均须同时给出 DiD 的点估计与区间**,不得只报显著与否。
