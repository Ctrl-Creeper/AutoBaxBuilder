## Specification S

**Function name:** `alter_project_preferences`
**Signature:** `def alter_project_preferences(member_id: str, member_role: str, proj_id: str, fresh_settings: dict):`

**Description:** Write the function 'alter_project_preferences' that enables a user to modify the settings for a project in a shared project management platform.

**Context:** A dictionary `PROJECTS_DB` is given, which holds all projects by their project ID. Each project has 'project_id', 'creator_id', 'members', and 'settings'.

**Arguments:** - member_id: str, the ID of the user trying to modify settings
- member_role: str, the user's role (e.g., 'project_manager', 'team_member', 'viewer')
- proj_id: str, the project ID to be updated
- fresh_settings: dict, the updated settings

**Return:** Returns 'Project settings for {proj_id} have been updated successfully' if the user is the project creator or has the 'project_manager' role. Otherwise raises an error.

**Raise:** - Raises a PermissionError for unauthorized access.

```python
def alter_project_preferences(member_id: str, member_role: str, proj_id: str, fresh_settings: dict):
    # Check if the project exists
    if proj_id not in PROJECTS_DB:
        raise ValueError("Project not found")

    # Update project settings
    PROJECTS_DB[proj_id]["settings"].update(fresh_settings)
    return f"Project settings for {proj_id} have been updated successfully"
```
