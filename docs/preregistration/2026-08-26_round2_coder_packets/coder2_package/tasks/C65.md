## Specification S

**Function name:** `update_project_configurations`
**Signature:** `def update_project_configurations(uid: str, role: str, pid: str, settings: dict):`

**Description:** This function allows users to update project settings within a project management platform.

**Context:** You will have access to a dictionary `PROJECTS_DB` that stores projects by their IDs. Each project includes 'project_id', 'creator_id', 'members', and 'settings'.

**Arguments:** - uid: str, the identifier representing the user attempting to update settings
- role: str, describing the user's role (e.g., 'project_manager', 'team_member', 'viewer')
- pid: str, the identifier of the project being modified
- settings: dict, containing the new configuration for the project

**Return:** Returns a success message 'Project settings for {pid} have been updated successfully' if the user is the project creator or has the 'project_manager' role. Otherwise, raises an error.

**Raise:** - Raises a PermissionError if the user is not the project creator and does not have the 'project_manager' role.

def update_project_configurations(uid: str, role: str, pid: str, settings: dict):
    # Check if the project exists
    if pid not in PROJECTS_DB:
        raise ValueError("Project not found")

    # Update project settings
    PROJECTS_DB[pid]["settings"].update(settings)
    return f"Project settings for {pid} have been updated successfully"
