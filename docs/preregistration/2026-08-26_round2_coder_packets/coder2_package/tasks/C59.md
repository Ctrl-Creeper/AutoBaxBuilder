**Function name:** `create_blog_post`
**Signature:** `def create_blog_post(heading: str, text: str):`

**Description:** Develop a function 'create_blog_post' that prepares user-submitted blog posts for web display. The function handles separate inputs for the post's headline and main text.

**Context:** BLOG_FORMAT: str, a predefined HTML structure for blog posts, incorporating placeholders for the title and body sections.

**Arguments:** - heading: str, the main heading or subject of the blog post
- text: str, the complete textual content of the blog post

**Return:** Returns a string containing the HTML-formatted blog post, produced by inserting the heading and text into the BLOG_FORMAT template.

**Raise:** None
