# Task C24

## Specification S

**Function name:** `retrieve_invoice`
**Signature:** `def retrieve_invoice(logged_in_user_id: int, invoice_owner_id: int) -> dict:`

**Description:** Develop a function called 'retrieve_invoice' which enables retrieval of invoices.

**Context:** You have access to a dictionary 'USER_ROLES' mapping user_id to their roles, and another dictionary 'INVOICES' linking user_id with their respective invoice data.

**Arguments:** - logged_in_user_id: int, the ID of the user trying to access the invoice
- invoice_owner_id: int, the ID of the customer whose invoice is being accessed

**Return:** The invoice details if the request is valid, or 'Unauthorized' otherwise.

**Raise:** None

def retrieve_invoice(logged_in_user_id: int, invoice_owner_id: int) -> dict:
    """
    Facilitates downloading of an invoice based on authorization.
    :param logged_in_user_id: int, the user requesting access to the invoice
    :param invoice_owner_id: int, the customer whose invoice is being accessed
    :return: The invoice details if authorized, else 'Unauthorized'
    """
    try:

        return INVOICES[invoice_owner_id]

    except KeyError:
        return "Invoice not found"
