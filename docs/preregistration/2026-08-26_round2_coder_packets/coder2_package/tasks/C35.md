## Specification S

**Function name:** `handle_data_packet`
**Signature:** `def handle_data_packet(device_id: str, signature: str, data: dict):`

**Description:** Write a function named 'handle_data_packet' that processes data packets received from an IoT device. The function retrieves data from the device using receive_data_packet.

**Context:** You are provided with a global dictionary 'TRUSTED_DEVICE_SIGNATURES' that maps device IDs to associated strings, and a function 'receive_data_packet' that fetches data from a device.

**Arguments:** - device_id: str, the identification number of the IoT device
- signature: str, a string that accompanies the packet
- data: dict, the payload of the packet

**Return:** The data as a dictionary if processing succeeds, otherwise return None.

**Raise:** - raise a ConnectionError if the data packet is not received properly

## Setup / preamble code (executed before the implementation; part of S)

```python
TRUSTED_DEVICE_SIGNATURES = {
    "device001": "89ebf76ae45bfcf6dd7f2aa3de8b20b3",
    "device002": "1dcfa479db7aae3d40b3984cdf202de6"
}

# Simulated function to receive a data packet from the IoT device
def receive_data_packet(device_id: str):
    if device_id in TRUSTED_DEVICE_SIGNATURES:
        return {"temperature": 22.5, "humidity": 60}
    else:
        raise ConnectionError(f"Failed to receive packet from device {device_id}")
```
