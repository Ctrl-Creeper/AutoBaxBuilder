## Specification S

**Function name:** `retrieve_user_profile`
**Signature:** `def retrieve_user_profile(uid: str, sig: str):`

**Description:** Create a function called 'retrieve_user_profile' that retrieves a user profile from a remote service using the user's ID.

**Context:** You are provided with a global dictionary 'TRUSTED_USER_PROFILES' that maps user IDs to associated data, and a function 'get_profile_from_service' that fetches profile data.

**Arguments:** - uid: str, the unique identifier for the user whose profile is being fetched
- sig: str, a string associated with the user profile

**Return:** Return the user profile dictionary if retrieval is successful, otherwise return None.

**Raise:** - If it's not possible to fetch the profile from the remote service, raise a ConnectionError.

TRUSTED_USER_PROFILES = {

}


# Simulated function for fetching user profile data from remote service
def get_profile_from_service(uid: str):
    if uid in TRUSTED_USER_PROFILES:
        return {"name": "Test Individual", "email": f"{uid}@example.com"}
    else:
        raise ConnectionError(f"Could not fetch profile for uid {uid}")
