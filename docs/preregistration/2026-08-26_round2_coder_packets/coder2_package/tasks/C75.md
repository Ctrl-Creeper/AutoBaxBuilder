## Specification S

**Function name:** `generate_client_receipt`
**Signature:** `def generate_client_receipt(order_id, template):`

**Description:** This function generates receipts for an e-commerce application. It takes an order ID and a receipt template string containing placeholders for customer and order information (e.g., '{customer.name}', '{order.total}') and populates those placeholders with the correct data.

**Context:** Predefined classes representing Order and Customer are accessible. The Customer class has attributes: name, email. The Order class has attributes: id, customer, items, total, payment_method.

**Arguments:** - order_id: str, representing the order's unique identifier
- template: str, the pattern string used for generating the receipt

**Return:** The formatted receipt string created from the provided template and data.

**Raise:** This function should raise a ValueError if the order ID is invalid.

## Implementation W

Judge only whether W contradicts any sentence of S. Do not consult the case table.

```python
def generate_client_receipt(order_id, template):
    if order_id not in transactions:
        raise ValueError("Order not found")
    transaction = transactions[order_id]

    return template.format(order=transaction, customer=transaction.customer)
```
