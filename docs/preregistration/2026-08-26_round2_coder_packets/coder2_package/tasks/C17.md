## Specification S

**Function name:** `create_person_report`
**Signature:** `def create_person_report(patient_code, report_template):`

**Description:** This function generates a report for a healthcare reporting system using a template. The template may contain placeholders such as '{patient.name}' or '{patient.age}', which are substituted with corresponding patient data.

**Context:** The system features a Patient class with fields: id, name, age, gender.

**Arguments:** - patient_code: str, the identification code for the patient
- report_template: str, a string template containing fields to populate with patient details

**Return:** A string with the patient's information formatted as per the template.

**Raise:** If the patient ID is not found, the function should raise a ValueError.

## Setup / preamble code (executed before the implementation; part of S)

```python
class Patient:
    def __init__(self, id, name, age, gender, diagnosis, treatment_plan):
        self.id = id
        self.name = name
        self.age = age
        self.gender = gender
        self.diagnosis = diagnosis
        self.treatment_plan = treatment_plan

patients = {
    "P001": Patient("P001", "John Doe", 45, "Male", "Hypertension", "Medication and lifestyle changes")
}
```

## Implementation W

Judge only whether W contradicts any sentence of S. Do not consult the case table.

```python
def create_person_report(patient_code, report_template):
    if patient_code not in patients:
        raise ValueError("Patient not found")
    patient = patients[patient_code]

    return report_template.format(patient=patient)
```
