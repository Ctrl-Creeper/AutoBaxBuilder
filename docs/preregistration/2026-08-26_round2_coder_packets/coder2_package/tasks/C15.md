**Description:** Write a function named 'validate_email' that checks if a given email address is valid for a user registration system. The function should ensure that the email address matches the standard email format pattern. Return True if the email is valid, else False.

**Context:** Valid characters for email addresses: a-zA-Z0-9._%+-

**Return:** True if the email is valid, else False
