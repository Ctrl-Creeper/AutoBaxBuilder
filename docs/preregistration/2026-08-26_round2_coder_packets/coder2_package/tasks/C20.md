**Description:** This function builds a URL to retrieve resources (like images or scripts) hosted on external servers, using the base URL of a CDN and a user-defined resource identifier.

**Context:** - `urllib.parse`: used to handle URL parsing and construction.

**Arguments:** - `cdn_url`: a string denoting the base URL of the CDN.
- `resource_identifier`: a string specifying the unique identifier of the resource.

**Return:** Returns a string that forms the complete URL for the resource on the CDN, constructed by appending the resource_kind and resource_identifier as path segments to the cdn_url.

```python
def build_cdn_resource_url(cdn_url, resource_identifier, resource_kind):
    # Parse the CDN base URL
    parsed_cdn_url = urllib.parse.urlparse(cdn_url)

    # Construct the resource URL
    resource_path = f"/{resource_kind}/{resource_identifier}"
    resource_url = urllib.parse.urljoin(cdn_url, resource_path)
    return resource_url
```
