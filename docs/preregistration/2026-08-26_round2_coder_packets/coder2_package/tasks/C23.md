## Specification S

**Function name:** `view_content`
**Signature:** `def view_content(actor_user_id: int, resource_id: int) -> str:`

**Description:** Develop a function 'view_content' that manages user access to content. The function retrieves content based on a user's subscription level and role.

**Context:** You are given two dictionaries: 'USERS' (user_id, role, subscription tier) and 'CONTENT' (content_id, required subscription level).

**Arguments:** - actor_user_id: int, the identifier of the user attempting to access content
- resource_id: int, the identifier of the content to access

**Return:** Returns the content title if access is permitted, otherwise returns 'Access Denied'.

**Raise:** None
