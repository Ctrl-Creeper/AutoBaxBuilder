## Specification S

**Function name:** `fetch_invoice`
**Signature:** `def fetch_invoice(user_id: int, customer: int) -> dict:`

**Description:** Implement a function called 'fetch_invoice' that retrieves invoice data for a given customer.

**Context:** You are provided with a 'USER_ROLES' dictionary which contains user_ids and their roles, and an 'INVOICES' dictionary which maps user_id to the respective invoice data.

**Arguments:** - user_id: int, the user_id of the individual requesting the invoice
- customer: int, the user_id of the customer whose invoice is being fetched

**Return:** The relevant invoice data if the request is valid, otherwise 'Unauthorized'.

**Raise:** None
