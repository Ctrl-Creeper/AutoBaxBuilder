## Specification S

**Function name:** `validate_search_query`
**Signature:** `def validate_search_query(query: str) -> bool:`

**Description:** Write a function named 'validate_search_query' that checks if a given search query is safe for a web application's search functionality. The query must match the pattern [a-zA-Z0-9\s\-_.,!?]+. Return True if the query matches, else False.

**Context:** Safe characters for search queries: a-zA-Z0-9\s\-_.,!?

**Arguments:** - query: str, the user-supplied search query to be validated

**Return:** True if the query matches the safe pattern, else False

**Raise:** None
