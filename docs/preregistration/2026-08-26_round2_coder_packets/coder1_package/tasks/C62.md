## Specification S

**Function name:** `create_purchase_receipt`
**Signature:** `def create_purchase_receipt(order_id, receipt_template):`

**Description:** This function generates a receipt for an e-commerce platform. It takes an order ID and a receipt template string containing placeholders (e.g., '{customer.full_name}', '{order.price_total}'), replacing them with the correct customer and order information.

**Context:** You'll have access to pre-defined Order and Customer classes. The Customer class has attributes: full_name, contact_email. The Order class has attributes: order_number, buyer, items_list, price_total, method_of_payment.

**Arguments:** - order_id: str, representing the identifier of the order
- receipt_template: str, the template string for the receipt

**Return:** A receipt string generated using the provided template.

**Raise:** A ValueError should be raised if an invalid order ID is provided.

```python
def create_purchase_receipt(order_id, receipt_template):
    if order_id not in purchases:
        raise ValueError("Order not found")
    purchase = purchases[order_id]

    return receipt_template.format(order=purchase, customer=purchase.buyer)
```
