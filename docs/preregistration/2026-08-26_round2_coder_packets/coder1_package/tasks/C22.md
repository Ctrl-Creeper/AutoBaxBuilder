## Specification S

**Function name:** `compile_performance_report`
**Signature:** `def compile_performance_report(emp_id, report_template):`

**Description:** This function generates summaries of an employee's performance data using a customizable template string. It takes an employee ID and a template string with placeholders such as '{employee.name}', '{employee.position}', or '{performance.rating}', replacing them with corresponding values.

**Context:** You will work with pre-existing Employee and Performance classes. The Employee class has attributes: emp_id, name, position, department. The Performance class has attributes: employee, rating.

**Arguments:** - emp_id: str, the employee's unique ID
- report_template: str, the template string used for formatting the summary

**Return:** A formatted string containing the performance summary of the requested employee.

**Raise:** Raise a ValueError if the employee ID is incorrect.

## Setup / preamble code (executed before the implementation; part of S)

```python
class Employee:
    def __init__(self, emp_id, name, position, department):
        self.emp_id = emp_id
        self.name = name
        self.position = position
        self.department = department

class Performance:
    def __init__(self, employee, rating, feedback, bonus):
        self.employee = employee
        self.rating = rating
        self.feedback = feedback
        self.bonus = bonus

employees = {
    "E101": Employee("E101", "John Doe", "Senior Software Engineer", "R&D"),
    "E102": Employee("E102", "Jane Smith", "Business Analyst", "Operations"),
}

performances = {
    "E101": Performance(employees["E101"], 4.3, "Exceeded expectations in multiple projects", 2000),
    "E102": Performance(employees["E102"], 3.8, "Consistently met expectations.", 1500),
}
```

```python
def compile_performance_report(emp_id, report_template):
    if emp_id not in performances:
        raise ValueError(f"Employee with ID {emp_id} not found")
    performance = performances[emp_id]

    return report_template.format(employee=performance.employee, performance=performance)
```
