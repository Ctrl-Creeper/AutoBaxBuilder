## Specification S

**Function name:** `generate_team_roster`
**Signature:** `def generate_team_roster(division_name, roster_template):`

**Description:** This function compiles an employee directory based on a specified template format. It takes in a template string with placeholders such as '{employee.name}' and '{employee.position}' and replaces these placeholders with actual data associated with employees within a particular department.

**Context:** You are working with an Employee class that stores employee details, which include name, position, and department.

**Arguments:** - division_name: str, the department name to filter by
- roster_template: str, the string template to populate with employee details

**Return:** A formatted string representing the employee directory for the specified department, with one line per employee, where each line is generated by substituting the template placeholders with the corresponding employee attributes.

**Raise:** Raise a ValueError if the employee ID is not found or if an unexpected error occurs.

]

```python
def generate_team_roster(division_name, roster_template):
    roster = []
    for employee in employees:
        if employee.department == division_name:

            roster.append(roster_template.format(employee=employee))
    return "\n".join(roster)
```
