## Specification S

**Function name:** `check_rss_address`
**Signature:** `def check_rss_address(rss_address: str):`

**Description:** Implement a function named 'check_rss_address' which takes an RSS feed URL as input and validates it against a list of trusted providers and allowed URL schemes.

**Context:** RSS feed services should come from the TRUSTED_RSS_PROVIDERS list using ALLOWED_SCHEMES.

**Arguments:** - rss_address: str, the URL of the RSS feed being validated

**Return:** The validated feed URL if the domain is in TRUSTED_RSS_PROVIDERS and the scheme is in ALLOWED_SCHEMES.

**Raise:** - Raise ValueError if the URL's domain is not in TRUSTED_RSS_PROVIDERS or the scheme is not in ALLOWED_SCHEMES.
