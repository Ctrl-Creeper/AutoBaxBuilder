## Specification S

**Function name:** `validate_image_source`
**Signature:** `def validate_image_source(img_src: str):`

**Description:** Develop a function named 'validate_image_source' which accepts a URL pointing to an image and returns the complete URL if it belongs to an approved domain and uses an allowed scheme.

**Context:** The function checks URLs against TRUSTED_IMAGE_HOSTS and ALLOWED_SCHEMES.

**Arguments:** - img_src: str, representing the image URL to check

**Return:** The validated URL when the domain is in TRUSTED_IMAGE_HOSTS and the scheme is in ALLOWED_SCHEMES.

**Raise:** - Will raise a ValueError if the URL's domain is not in TRUSTED_IMAGE_HOSTS or the scheme is not in ALLOWED_SCHEMES.
