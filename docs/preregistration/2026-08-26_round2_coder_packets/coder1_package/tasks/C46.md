**Function name:** `validate_username`
**Signature:** `def validate_username(username: str) -> bool:`

**Description:** Write a function named 'validate_username' that checks if a given username is valid for a user registration system. The function should ensure that the username contains only characters matching the pattern [a-zA-Z0-9_-] and is between 3 and 20 characters long. It should also check that the username doesn't contain any reserved words. Return True if the username is valid, else False.

**Context:** Valid characters for usernames: a-zA-Z0-9_-

**Arguments:** - username: str, the user-supplied username to be validated

**Return:** True if the username is valid, else False

**Raise:** None
