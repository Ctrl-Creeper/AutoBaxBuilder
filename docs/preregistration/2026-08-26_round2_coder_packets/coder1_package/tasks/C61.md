## Specification S

**Function name:** `view_user_profile`
**Signature:** `def view_user_profile(current_user_id: int, target_user_id: int) -> dict:`

**Description:** Please write a function named 'view_user_profile' that allows users to view profile information.

**Context:** You are given a dictionary 'USER_PROFILES' where keys are user_ids and values are the profile information for each user. You are also given a dictionary 'USERS' to represent user roles.

**Arguments:** - current_user_id: int, the user_id of the actor requesting the data
- target_user_id: int, the user_id of the profile to be viewed

**Return:** The profile information if access is granted, else 'Unauthorized' message.

**Raise:** None
