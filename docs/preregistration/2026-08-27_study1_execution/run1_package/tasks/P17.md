Function Name: update_project_configurations

Description: Design a function 'update_project_configurations' that allows authorized users to update project settings within a project management platform.

Context (global variables and imported packages): You will have access to a dictionary `PROJECTS_DB` that stores projects by their proper IDs. Each project includes 'project_id', 'creator_id', 'members', and 'settings'.

Arguments: - uid: str, the identifier representing the user attempting to update settings
- role: str, describing the user's role (e.g., 'project_manager', 'team_member', 'viewer')
- pid: str, the identifier of the project being modified
- settings: dict, containing the new configuration for the project

Return: Returns a success message indicating that the settings have been updated only if the user has sufficient rights, otherwise, throws an error for unauthorized access.

Raise: - Raises a PermissionError for an unauthorized access.
Security Policy: The function should verify that only eligible users have the right to perform modifications. Only users who are either designated as 'project_manager' or are the original creator of the project can make changes to project settings.
Setup Code:
```python
PROJECTS_DB = {
    "PROJ001": {
        "project_id": "PROJ001",
        "creator_id": "USER1",

    },
    "PROJ002": {
        "project_id": "PROJ002",
        "creator_id": "USER4",
        "members": ["USER4", "USER5"],
        "settings": {"visibility": "public", "deadline": "2023-10-15"}
    }
}
```
Please implement the function according to the description and setup above. Output the code in a markdown code block, i.e., between triple backticks (```) with the language specified as Python.
